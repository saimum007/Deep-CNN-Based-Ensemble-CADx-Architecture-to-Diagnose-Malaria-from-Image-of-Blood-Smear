# Deep-CNN-Based-Ensemble-CADx-architecture-to-Diagnose-Malaria-from-Image-of-Blood-Smear
This project presents a CNN-based CADx system using VGG-19 and ResNet-50 ensembles for malaria detection. Trained on NIH microscopic images, the optimal model achieved 96.7% patient-level accuracy- excelling in remote/emergency settings
