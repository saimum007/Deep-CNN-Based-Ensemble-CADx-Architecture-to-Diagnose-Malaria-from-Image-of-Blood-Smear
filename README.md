# Deep-CNN-Based-Ensemble-CADx-architecture-to-Diagnose-Malaria-from-Image-of-Blood-Smear
This work presents a computer-aided diagnosis (CADx) method leveraging deep convolutional neural networks (CNNs) to assist in the reliable and rapid detection of malaria. Using VGG-19 and ResNet-50 architectures, models were developed to classify parasitized and uninfected erythrocytes. An ensemble technique was employed to enhance performance, with the best model selected based on evaluation metrics. Tested on a standard NIH microscopic image dataset, the proposed model achieved a high accuracy of 96.7% for patient-level detection. This approach demonstrates its potential as an effective tool for automated malaria detection, particularly in remote and emergency scenarios
